Pacchetto Installatore

Windows / macOS / Linux · 1006 KB · crea l'icona sul Desktop

v1.0.0

Installa l'app in 3 passi

  1. Apri il file scaricato ed estrai tutto (tasto destro > «Estrai tutto...»).
  2. Nella cartella estratta fai doppio clic su INSTALLA-WINDOWS.bat.Se Windows avvisa «Windows ha protetto il PC»: «Ulteriori informazioni» > «Esegui comunque».
  3. Sul Desktop compare l'icona Omar AI: doppio clic e Omar si apre nella sua finestra.

Servono Node.js 22.13+ e Ollama (gratuiti). Al primo avvio Omar scarica i modelli IA (circa 8 GB, una volta sola). Omar AI è solo un'applicazione: non c'è una versione web, si apre dall'icona. L'IA gira sul computer: conversazioni e file non lasciano la scuola.

Nessuna registrazione richiesta per il download standard.
